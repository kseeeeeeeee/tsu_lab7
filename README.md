## Цель работы

Изучить работу с различными системами управления базами данных в Python, освоить обновление записей SQLite, использование параметров SQL-запросов, работу с SQLAlchemy, транзакциями и асинхронный доступ к базам данных.

## Выполненные задания

### 1. Средняя сложность № 4 — Обновление записи в SQLite
**Файл:** `lab7/sqlite_update.py`

Создана программа для работы с базой данных SQLite. Реализовано обновление зарплаты сотрудника с помощью SQL-запроса UPDATE.

### 2. Средняя сложность № 6 — Использование параметров в SQL-запросах
**Файл:** `lab7/sqlite_parameters.py`

Реализованы параметризованные SQL-запросы для поиска сотрудника и изменения его должности. Использование параметров позволяет безопасно передавать значения в запросы.

### 3. Средняя сложность № 10 — Использование SQLAlchemy для одной таблицы
**Файл:** `lab7/sqlalchemy_single.py`

Создана модель таблицы студентов с помощью SQLAlchemy. Реализовано создание таблицы, добавление записей и вывод списка студентов.

### 4. Повышенная сложность № 5 — Работа с транзакциями
**Файл:** `lab7/sqlite_transactions.py`

Реализованы транзакции перевода денежных средств между двумя банковскими счетами. Добавлено ограничение CHECK (balance >= 0), предотвращающее отрицательный баланс. Проверены успешный перевод и ситуация недостаточности средств: при нарушении ограничения возникает ошибка, выполняется rollback. Состояние счетов до и после отката сравнивается, что подтверждает отмену изменений.

### 5. Повышенная сложность № 9 — Асинхронный доступ к базе данных
**Файл:** `lab7/async_database.py`

Реализован асинхронный доступ к базе данных SQLite с использованием библиотек databases и aiosqlite. Выполняются добавление пользователей и получение списка записей.

## Результат

Все пять заданий выполнены и проверены. Реализованы обновление записей, параметризованные запросы, работа с SQLAlchemy, транзакции и асинхронное взаимодействие с базой данных.
